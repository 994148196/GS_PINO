# exp010 — 混合训练消融：无 config 通道（仅 up 占位自推断）

> 实验日期：2026-08-17
> 状态：**完成**（N=500，seed 1）
> 代码：`src/gs_pino_dn_fno_2608/`（`train_dn_fno --input-mode xa`，无
> `--config-input`，与 exp009 同 13ch 输入）
> 数据：`dn_fno_2608/data_v5/`（MAST DN+SN 拼接，同 exp008）
> 对照：exp008（混合 + config 1ch，14ch）；exp009（专职 13ch）
> 动机：exp008 反事实测试证明模型**依赖**显式 config 标签（翻转 → 22–54×
> 崩溃）。但 config 与 up=(0,0) 占位在训练数据中 100% 冗余——本消融去掉
> config，强迫模型只靠占位结构自推断位形。
> 结论速览：**模型完全可以自推断位形**——无 config 的混合模型两桶都健康
> （DN 0.611% / SN 1.148%），且略优于带 config 的 exp008（0.667/1.203%）。
> exp008 中模型"用"config 标签只是因为它与 up 占位完全冗余、省力；
> 部署时无需位形标签，up=(0,0) 占位编码即物理自包含。

---

## 1. 动机与科学问题

exp008 的 config 反事实（notes §4b）：测试时把 config 通道翻转（DN 喂
z(1)、SN 喂 z(0)）→ DN test rel L2 0.667%→36.2%（54×）、SN test
1.203%→27.2%（23×）——**模型确实在用显式标签，没有"自己推断"**。

但"用了"≠"不能不用"。SN 样本的 up X 点通道是 (0,0) 占位（z-score 后
恒值常数），DN 的变化——输入本身完全可分。本实验问：

**去掉 config 通道后，混合模型能否仅靠 up 占位结构区分 DN/SN 并保持
两个桶都健康？**

- 若健康（≈exp008 的 0.667/1.203%）→ 占位自推断足够，config 标签冗余，
  部署时无需位形标签（物理自包含输入）；
- 若退化为外推级崩溃（≈253% 量级）→ 模型学不会利用恒值通道结构，
  显式标签是必需的（至少对当前架构/N 如此）。

## 2. 方法

- 训练：N=500 seed 1，`--input-mode xa` **无 `--config-input`** → 13 通道
  （R, Z + 5 params + 4 X点 + 2 锚点），与 exp009 专职模型同输入架构；
- 数据：train/val = dn+sn 拼接（同 exp008），测试分桶 dn/sn 各自；
- 归一化：拼接 pool 的共享 stats（同 exp008；SN 的 up 恒值通道由
  `np.maximum(std, 1e-8)` 防护为 0——注意：混合 pool 下 up 通道 std
  非零（DN 贡献），SN 样本 z-score 后为恒值常数，非 0）。

## 4. 结论

1. **模型能自己推断位形**：去掉 config 通道后，混合模型仅凭 up=(0,0)
   占位恒值通道（SN）vs 变化值（DN）的结构区分两类——DN 桶 0.611%、
   SN 桶 1.148%，与专职外推崩溃（253% / 4.0e8%）隔了三个数量级。
2. **无 config 反而略好**（DN 0.611 vs 0.667、SN 1.148 vs 1.203、val
   0.833 vs 0.879）：显式标签通道让模型"偷懒"走条件映射捷径；去掉后
   模型必须建立统一的、位形自包含的映射，训练损失更干净（也许正是
   用户直觉"它应该自己能推断出来"的机制）。
3. **与 exp008 反事实的合成结论**：翻转 config 会崩溃（用了标签）≠
   没有标签会崩溃（消融证伪）。模型在冗余信号下优先用显式标签，但
   去掉后占位结构足够——**config 通道是冗余的，可安全删除**。
4. 部署启示：输入按"存在的 X 点"编码（SN 的 up 填占位 (0,0)）即可，
   无需位形标签；exp008 的 14ch 设计可简化为 13ch（exp010/exp009 架构）。

## 5. 偏差记录

1. DN 桶 find_critical 失败 1/500（exp008 为 0/500）：单样本定位失败，
   来自模型输出场的局部噪声，不影响 rel L2 结论（同类个案在 exp009
   专职 DN 也存在，MAST 无墙下 find_critical 对 DN 双 X 点更敏感）。
2. GS 残差比值 SN 桶 0.977（exp008 0.984）：仍在 1 附近（真值 1.288），
   属于残差分布的正常波动，与 exp009 专职 SN（0.991）同量级。
