# exp009 notes — 专职单一位形（DN-only / SN-only）对照解读

> 2026-08-17 训练与评估。配套 README.md（设计/结论）与 data_v5/README.md。
> 对照 exp008（混合训练）。N=500 seed 1，延续惯例。

## 1. 数据（data_v5）

- 专职 DN 用 dn/*.npz、专职 SN 用 sn/*.npz（各 train 2000/val 500/test 500，
  500/500 全接受）。

## 4. 解读

1. **专职 > 混合（自身配置）**：DN 0.492 vs 0.667、SN 0.953 vs 1.203——
   单一位形内数据分布更窄，专职模型把全部容量用于该位形。
2. **外推失败的两种形态**：
   - DN→SN（253%）：DN 模型从未见过"上 X 点通道恒 0"的输入。输入分布
     外推时输出场仍"像 DN"（残差比 2.27 说明场量级错），rel L2 中位数
     244% ≈ 预测与真值接近正交；
   - SN→DN（4.0e8%）：上 X 点通道突然非零，模型输出完全无物理意义
     （残差比 1024、RMSE 1.8e5 Wb——比场本身大 9 个数量级）。
     两种形态都说明**没有学到物理一致的映射**，只有位形内的查表。
3. **交叉外推为何崩溃而混合不崩**：混合模型训练时同时见过两种分布，
   config 通道提供条件信号（SN 恒 0 up 通道 + config=1 → SN 分支）。
   FNO 是分布内插值器，外推无保障——这与 exp006 结论"输入信息完整 +
   目标物理一致"一脉相承：**训练分布覆盖是必要条件**。
4. 工程启示：生产部署若位形集合固定 → 每位形专职模型（误差更小）；
   若需位形切换/增量扩展 → 混合池 + config 通道（代价 26–35% 可量化）。

## 5. 后续可做

- 交叉失败的反事实：混合模型对专职模型的输入换 config 通道（0↔1）看
  预测是否随 config 切换——验证条件映射的因果性；
- 外推失败梯度：逐步注入 SN 样本（5%/10%/25%）看 DN 模型恢复速度，
  标定混合池的最小配置比例。
