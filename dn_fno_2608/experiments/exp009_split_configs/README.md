# exp009 — 专职单一位形训练（DN-only / SN-only 对照）

> 实验日期：2026-08-17
> 状态：**完成**（N=500，seed 1）
> 代码：`src/gs_pino_dn_fno_2608/`（`train_dn_fno --input-mode xa`，无 config 通道）
> 数据：`dn_fno_2608/data_v5/`（MAST DN/SN 分开落盘，各 3000）
> 对照：exp008（混合位形训练，config 输入）
> 结论速览：**专职模型在自身配置上最优（DN 0.492%、SN 0.953%），但跨配置
> 外推崩溃（DN→SN 253%、SN→DN 4.0e8%）——单一位形训练没有学到跨位形
> 的一致映射；混合训练（exp008）以 +26~35% 代价换来两个配置都可用。

---

## 1. 动机与科学问题

exp008 混合训练的核心对照：**专职单一位形（DN/SN 各自训练）** 的性能基线。
科学问题：混合训练相比专职训练的代价/收益是多少？

- 专职 DN 模型：只见过 DN 样本（含 2 X 点 + 上 X 点通道非零）；
- 专职 SN 模型：只见过 SN 样本（上 X 点通道恒 0 占位——std 防护下自动
  映射为 0 通道，模型学习忽略它）；
- 跨配置交叉评估（DN 模型 → SN test 等）量化**配置外推**能力（混合训练
  的理论优势）。

## 2. 方法

- 训练：N=500 seed 1，MSE/AdamW/ReduceLROnPlateau，同 exp006 惯例；
- 输入：`--input-mode xa` → **13 通道**（R, Z + 5 params + 4 X点 + 2 锚点），
  无 config 通道；
- 数据：`model_dn_13ch` 用 `dn/*.npz`，`model_sn_13ch` 用 `sn/*.npz`；
- 评估：自身 test + 交叉 test（对方配置，量化配置外推）。

## 3. 结果

### 3a. 专职基线（自身 test）

| 指标 | 专职 DN | 专职 SN |
|---|---|---|
| rel L2 mean % | **0.492** | **0.953** |
| rel L2 median % | 0.411 | 0.818 |
| rel L2 p95 % | 1.010 | 1.908 |
| RMSE phys (Wb) | 1.85e-04 | 4.31e-04 |
| GS 残差比值 | 0.9876 | 0.9906 |
| find_critical 失败 | 0/500 | 0/500 |
| sep_mean 误差 (cm) | 25.6 | 2.0 |

训练：DN best val rel L2 0.4903%（epoch 795，11.1 min）、SN best val
0.8834%（epoch 797，11.1 min）。

### 3b. 交叉评估（配置外推，rel L2 mean %）

| 模型 | DN test | SN test |
|---|---|---|
| 专职 DN | 0.492 | **253.4**（外推崩溃） |
| 专职 SN | **4.0e8**（完全失效） | 0.953 |
| 混合（exp008） | 0.667 | 1.203 |

交叉详情：专职 DN 模型喂 SN 样本 rel L2 253%（中位数 244%，RMSE 1.0e-1 Wb、
GS 残差比 2.27——预测场与真实场量级严重偏离）；专职 SN 模型喂 DN 样本
rel L2 4.0e8%（中位数 4.1e8%、RMSE 1.8e5 Wb、GS 残差比 1024——输出完全
无物理意义）。交叉评估仅用于量化外推失败，不参与任何指标汇总。

## 4. 结论

1. **专职基线成立**：DN-only / SN-only 各自训练在自身 test 上优于混合模型
   （0.492% vs 0.667%、0.953% vs 1.203%）——单一位形内，专职学习更充分。
2. **单一位形训练没有跨位形泛化能力**：SN 样本的上 X 点通道恒 0 占位，
   DN 模型从未见过该分布，输入空间外推直接崩溃；反之 SN 模型面对 DN 的
   2-X-点输入同样失效。这说明模型学到的是**位形内的映射**，而非物理一致的
   "任意位形 → GS 平衡"映射。
3. **混合训练是跨位形泛化的必要条件**（与 exp008 §4 互证）：config 通道
   让混合模型在两种输入分布间切换映射，两个桶都健康。
4. 若生产场景只需要单一固定位形 → 专职训练更优（省 +26~35% 误差）；
   需要多位形/位形切换 → 混合训练是唯一可行解。
