# exp107 — 纯数据基线 DN-only（论文表 2 公平性修正）

> 实验日期：2026-09-16 ｜ 状态：**完成**（N=500，seed 1，data_v5/dn 单一位形）
> 数据：`data_v5/dn/`（MAST DN，65×65，2000/500/500，无墙）
> 动机：论文表 2 的"纯数据基线"此前取自 exp011（DN+SN 混合训练，coil 18ch）的
> DN 桶指标——混合训练自身有跨位形共享容量代价，对 DN 单位形对比不公平。
> 本实验按 exp011 完全相同的设置**去掉 SN 数据**重训一个纯数据基线，
> 与 exp101/102（同样只用 500 DN 样本）严格同口径。
> 结论速览：DN-only 纯数据基线 rel L2 **0.799%**（旧表 2 数字 0.841%），
> X 点 2.16/1.46 cm（旧 3.16/2.23）——**物理残差增益结论保持**（单阶段
> −10%、两阶段与基线持平但多出自洽能力）；GS 残差经口径修正后基线
> 3.07×（详见 §5/§7），表 2 基线列换用本实验数字

## 1. 目标

论文表 2 对比"纯数据基线 vs 方案 1（单阶段物理残差）vs 方案 2（两阶段自洽）"。
exp101/102 只用 500 个 DN 样本训练；旧基线 exp011 却是 DN+SN 混合训练后取 DN
桶指标——基线多扛了一份混合代价，对比不公平。本实验补一个**只用 500 DN
样本**的纯数据基线：除数据外与 exp011 逐项一致（coil 18ch 输入、纯 MSE、
直出 psi_total），使表 2 三列训练数据严格相同。

## 3. 模型与损失（与 exp011 逐项一致，仅数据去掉 SN）

- **直接预测 psi_total**（z-score 单输出）：无 coil 分离、无物理残差、无 J
  通道——论文 §3.2 对"纯数据管线"的定义；
- 损失 = 纯 MSE（z-score psi_total 域）；
- FNO2d2608：lift 18→64 + 4×FNOBlock（width 64, modes 16×16）+ proj 64→1，
  **4,212,225 参数**（与 exp011/exp101 完全一致）；
- AdamW lr 1e-3 / wd 1e-4，ReduceLROnPlateau（patience 20，factor 0.5，
  min_lr 1e-5），early stop patience 75，batch 16，**800 epochs 跑满**
  （早停未触发，21.2 min）；
- N=500（2000 池嵌套子集，**perm seed 12345** → 训练子集与 exp101/102
  完全相同）、seed 1。

## 5. 结论

1. **场精度**：DN-only 基线 0.799% 优于混合基线 0.841%（−5%）——混合训练
   在场精度上的代价存在但不大；
2. **几何定位是混合训练的主要代价**：X 点 −32%/−35%（2.16/1.46 vs
   3.16/2.23 cm）、磁轴 −17%（0.44 vs 0.53）、分离面 −20%（0.50 vs 0.62）；
3. **物理残差增益在公平基线下保持**：单阶段 0.715% vs 0.799%（−10%）；两
   阶段 0.800% 与基线持平（median 0.642 vs 0.666、P95 1.59 vs 1.72 略优）
   ——两阶段在不多花精度的前提下多出 J/Ip 自洽能力（纯数据管线无法获得）；
4. **X 点"厘米级 → 亚厘米级"结论成立**：基线 2.16/1.46 cm vs 两方案
   0.55–0.63 cm，§4.2 数字由 3.16/2.23 更新为 2.16/1.46；
5. **GS 残差口径修正（本实验的第二个产出）**：论文表 2 原基线列 1.01× 与方
   案列 3.31×/3.75× 不可比——基线用几何等离子体 mask（真值自身残差 127%，
   近轴差分截断误差主导，分母巨大），方案用芯部 mask 测等离子体分量（真值
   地板 0.40%）。统一到芯部 mask 后：基线 3.07×（exp107）/ 3.79×（exp011），
   与方案 3.31×/3.75× 同量级——**物理方案并未使物理一致性变差**，所有模型
   均处于各自真值差分地板的 3~4 倍；
6. **表 2 基线列换用本实验数字；表 3（混合对比）保留 exp011**——混合对比
   本来就是 exp011 的口径，exp011 实验本身不受影响。

## 7. 口径注记

- rel L2 / RMSE / 几何指标：evaluate_dn_fno 对 psi_total 计算，与
  exp011/exp101/102 同一脚本同一口径（n_find_critical_fail = 0）；
- **GS 残差（表 2 采用芯部口径）**：`gs_residual_ratio`（65² 二阶中心差分
  Δ*ψ vs 数据集 RHS −μ0R²p′−FF′，相对 L2 ‖Δ*ψ−RHS‖/‖RHS‖）作用于
  **psi_total 全场** + npz `mask`（freegs 芯部掩膜，去近轴点）；真值场地板
  7.2%（线圈场在芯区边界的差分误差叠加，高于 exp101/102 等离子体分量的
  0.40% 地板）；倍数 = pred/truth，与方案列"各自相对自身真值地板"语义一
  致。几何 mask 口径（含近轴，真值地板 127%）仅作参考，两口径明细见 §4；
- 与 exp101/102 的架构差异（有意保留，即论文基线定义）：基线直出
  psi_total、无 coil 分离、无 J 通道，因此没有 Ip/J 指标。
