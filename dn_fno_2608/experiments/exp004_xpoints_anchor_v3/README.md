# exp004 — X 点输入在锚点大变化下的可靠性（data_v3，X点 vs X点+锚点）

> 实验日期：2026-08-14 ｜ 状态：**完成**（N=500，seed 1，三模型对比）
> 数据：`data_v3/`（X 点 ±0.20 m + 锚点采样；**数据集已删除**——isoflux 约束
> 不可达缺陷，被 data_v4 取代；复现脚本 `scripts/run_generate_v3.sh` 保留）
> 对照：exp005（coil 版 B 模型，同数据）
> 结论速览：X 点输入在锚点大变化下**不可靠**（test rel L2 31.1%，一对多映射）；
> A'（+锚点 21.7%）、B（coil 12.5%）信息完整也远不足——**当时归因数据量瓶颈
> （已被 exp006 在 data_v4 上修订为约束不可达）**。coil 输入最好且各桶平坦。

## 1. 目标

data_v3 放开两个几何自由度采样：X 点 ±0.02→±0.20 m、isoflux 锚点固定→
R∈[1.2,1.8]×Z∈[−0.3,0.3] 采样。isoflux 约束使分离面必须同时穿过 X 点和锚点
→ 锚点变化改变分离面形状（非磁通 gauge）。于是：
- **A（仅 X 点 11ch）**：输入不含锚点信息 → 同一输入对应多个 psi 场（一对多）
  → 预期大幅退化；
- **A'（X 点+锚点 13ch）**：包含全部约束信息 → 上界对照。

量化"缺锚点信息"的代价。

## 2. 输入通道

| 模型 | 通道 |
|---|---|
| A（11ch） | R, Z + Ip, paxis, fvac, alpha_m, alpha_n + R_lo, Z_lo, R_up, Z_up |
| A'（13ch） | A + R_anc, Z_anc |

同数据（data_v3）、同规模（N=500 seed 1）、同超参（与 exp002/003 一致）。
代码：A 复用 train_dn_fno（零改动）；A' 用 `--input-mode xa`（新增路径）。

## 3. 结果（test 499）

| 指标 | A X点 11ch | A' X点+锚点 13ch | B coil 11ch (exp005) | exp002 (data_v2) 参考 |
|---|---|---|---|---|
| rel L2 mean % | 31.09 | 21.72 | **12.47** | 0.303 ± 0.227 |
| rel L2 median % | 25.88 | 12.70 | **8.37** | 0.242 |
| RMSE phys (Wb) | 1.04e-2 | 7.88e-3 | 3.85e-3 | 8.23e-5 |
| GS 残差比 | 1.034 | 1.219 | 1.245 | 0.996 |
| find_critical 失败 | 21/499 | 48/499 | 35/499 | 1/500 |

训练（val，均早停）：A 29.57% @e18｜A' 20.68% @e356｜B 12.99% @e220。

**锚点分桶（rel L2 mean %）**：
- 按距默认锚点 (1.5,0)：<0.2 m → A 25.2 / A' 16.5 / B 11.2；0.2–0.4 m → 35.3 / 25.4 / 13.4
- 按距最近 X 点：<0.3 m → 52.5 / 54.2 / **8.6**；0.3–0.6 m → 39.5 / 31.5 / 12.9；≥0.6 m → 25.3 / 14.6 / 12.4

## 4. 结论

1. **仅 X 点输入不可靠（31.1% vs 基线 0.3%，退化 100×）**——一对多映射被分桶
   证实：误差随锚点偏移增大（25→35%），锚点贴 X 点最高（52.5%）；
2. **信息完整也救不了 N=500**（A' 21.7%、B 12.5%）——当时结论为 data_v3
   解空间复杂度爆炸、数据量瓶颈（**exp006 在 data_v4 修订：主因是 isoflux
   约束不可达，真值分离面大多不过锚点**）；
3. **coil 输入相对最可靠**：整体最好、全桶平坦、近退化区最优（8.6%）——
   Tikhonov 电流解是锚点的确定性函数，映射更"因果"；
4. 直接回答：X 点与锚点都 ±0.2 m 量级变动时，N=500 下任何输入模式都不可靠。

## 7. 偏差记录

data_v3 两个未检查缺陷（**是后续 data_v4 的动机**）：
1. **isoflux 约束不可达**：4 线圈对 6 约束过定，|psi(X点)−psi(锚点)|/core mean
   0.50、max 2.10——多数样本真值分离面不通过锚点（A' 输入"完整信息"仍是假信息）；
2. **采样越界**：X 点/锚点范围大量落在线圈四边形凸包之外。
