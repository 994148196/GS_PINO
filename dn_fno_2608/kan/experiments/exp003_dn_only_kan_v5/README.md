## 2. 训练设置（与 exp001 完全一致，仅数据不同）

- N=500（dn/train.npz 2000 行上嵌套取 500）seed 1，MSE/Adam(1e-3)/MultiStepLR
  [300,500,700,900]×0.5，1000 epochs，每 epoch 32 样本 × 256 点
- 四阶段同一次训练：t<120 监督；120≤t<240 λPDE/λIp 生效；240≤t<600
  +λ(t)Lreg 斜坡至 0.001；t=600 剪枝（阈值 1e-2·max 连接强度）；之后微调至 1000
- λ(t) 按论文式 16：0 → 线性(120–240) → 恒 0.001(240–600) → 0(≥600)
- LPDE 用解析导数，排除线圈单元+边界；LIp 无偏等离子体地层估计器；
  best 相位感知（剪枝前后分开跟踪）
- 参数量：1260（19→10→2，210 连接 × 6）——与 exp001 相同
