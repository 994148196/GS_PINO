# exp002 — KAN 19ch 容量增强变体（hidden 24 / grid 4 / 2000 ep）

> 实验日期：2026-08-19 ｜ 状态：训练准备就绪
> 数据：`data_v5/`（MAST DN+SN，N=500，seed 1）——与 exp001 完全同源同子集
> 输入通道：**19 通道，明细同 exp001 §1**（R, Z + 5 params + config + 11 线圈电流，
> min-max [−1,1]；ψ/J 输出 z-score）——不再重复抄表
> 动机：exp001 M1 收敛到 ~19-20% val rel L2 平台（验收 ≤1.4% 未达标），
> 判定为点式 KAN 容量受限（FNO exp011 0.894%）。本实验在不动论文方法
> （监督→半监督→剪枝→微调四阶段、λ(t) 式 16、LPDE/LIp/Lreg 定义）的前提下
> 放大网络与训练长度。

## 1. 与 exp001 的差异（唯一变量，其余超参完全一致）

| 超参 | exp001（论文 arch） | exp002 |
|---|---|---|
| hidden | 10（1 隐含层） | **24**（仍 1 隐含层） |
| grid_size（B 样条每维区间数） | 2 | **4** |
| degree | 2（论文"3 阶"= 二次） | 2（不变） |
| epochs | 1000 | **2000** |
| milestones（LR ×0.5） | 300,500,700,900 | 600,1000,1400,1800（2× 缩放） |
| λ(t) 边界 b120/b240/b600 | 120/240/600 | 240/480/1200（按 epochs/1000 缩放） |
| 剪枝 epoch | 600 | 1200（= 60% 轮次，论文比例不变） |
| 参数量 | 1260 | **4536** |
| 其余（N/seed/采样/loss 权重/剪枝阈值/best 相位感知） | — | 与 exp001 相同 |

缩放原则：论文的 λ 窗口与剪枝时机是按"占全程 12%/24%/60%"定义的，
epochs 翻倍时按同比例平移，保持论文式 16 的四段形状不变。

## 2. 训练设置（同 exp001，仅上面列出的变量）

- N=500（拼接 4000 样本嵌套取 500）seed 1，MSE/Adam(1e-3)/MultiStepLR ×0.5
- 每 epoch 32 样本 × 256 点，stratified 50/50
- 四阶段：t<240 监督 → 240≤t<480 λPDE/λIp+λ(t) 斜坡 → 480≤t<1200 λ=0.001 恒
  → t=1200 剪枝（1e-2·max 连接强度，67/210 级）+ 冻结 → 微调至 2000

## 4. 偏差记录

- **宽度/网格/时长偏离论文标称**（hidden 10→24、区间 2→4、epochs 1000→2000）：
  论文架构在 14ch 较简单问题上报 0.631%，但 19ch MAST 混合位形 + 11 线圈
  输入的点式映射明显更难（exp001 实测 19-20% 平台）；本实验是容量杠杆的
  受控放大，方法学（四阶段、λ 式 16、损失项、剪枝语义）不变
- 其余偏差（LPDE 无 L_coils、LIp 无偏化、box 包络等）同 exp001 §4
