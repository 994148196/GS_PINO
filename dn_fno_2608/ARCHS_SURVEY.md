# GS 方程 ψ 预测的物理约束网络架构调研（exp3xx 系列依据）

> 2026-09-01 · 针对问题：**MAST 65² 网格、给定 18ch（R,Z + 5 等离子体标量 + 11 线圈电流）
> 预测 ψ_plasma，GS 方程 Δ\*ψ + μ₀R J_φ = 0 作物理约束**。
> 基线 exp102（FNO2d2608 两阶段 PINO，test rel L2 0.80%）；已有 KAN 轨经验：
> 点式 B-spline KAN（`gs_pino_kan_2608`）容量不足失败于 20.87%。

## 结论速览（→ exp301–304 实测）

| 骨架 | 文献证据 | 对 GS 的适配点 | 风险/预期 |
|---|---|---|---|
| **U-Net CNN** | EXL-50U 基准（arXiv 2608.23217）：CNN 在精度/稳健性/速度上最佳平衡，与 FNO 并列 OOD 外推最稳 | 局部卷积归纳偏置天然匹配椭圆型方程的光滑解；J 由 ψ 二阶导决定，局部结构重要 | 感受野 65² 全覆盖（depth 4 + 64² 底） |
| **UFNO 傅里叶 U-Net** | 局部+全局核混合的成熟范式（repo 遗留 UFNO2d_v2 可参考） | 编码器逐级降分辨率 + 谱卷积：高分辨率层保留细节、低分辨率层捕获全局磁面结构 | 多尺度参数利用率高（2.47M） |
| **FNO-KAN 混合** | KANO：纯谱瓶颈网络在**变系数** PDE 上失效；GS 恰为变系数（Δ\* = ∂²/∂R² − (1/R)∂/∂R + ∂²/∂Z²，R 因子） | 谱核做全局混合 + KAN 做逐点可学习激活（比固定 GELU 表达力强）；保留 FNO 的全局卷积优势 | 点式 KAN 前车之鉴：本次是 FNO 骨架 + KAN 作块内混合，非纯 KAN |
| **PI-DeepONet** | SUNIST-2（IAEA 2025）：GS 平衡重构约束只需 ~100 个放电样本；Cai et al. CMAME 2022：DeepONet 对噪声输入稳健 | 分支网络吃 16 标量（5 等离子体参数 + 11 线圈电流），trunk 吃 (R,Z)——恰好是本问题的输入分解结构 | 0.60M 参数容量小；trunk 逐点评估天然可加物理损失 |
| **WNO**（暂缓，仅记录） | 局部化小波核，理论上适合 65² 非 2 的幂网格 | — | 依赖 pywt + 额外包，收益未证实，留作未来选项 |

## 1. 问题特征决定架构需求

1. **解的结构**：ψ(R,Z) 是椭圆型方程的光滑解，全局磁面拓扑（O 点/X 点）由边界条件与线圈电流决定 → 需要**全局感受野**（FNO/UFNO 的谱卷积，或足够深的 U-Net）。
2. **变系数**：Δ\*ψ 含 1/R 项 —— KANO 的核心论点是纯谱瓶颈（只做 Fourier 混合）在变系数 PDE 上谱效率退化，需要逐点非线性/局部结构 → 支持 KAN 混合与局部卷积的动机。
3. **输入-输出维度**：输入大部分是**全局标量**（Ip、paxis、fvac、α 分布、11 线圈电流）而非场 → DeepONet 的分支-主干分解天然吻合；FNO 系列靠广播把这些标量铺到全网格。
4. **物理约束形式**：GS 残差、Ip 积分约束都作用在**场函数上**（`losses_pino.py` 已实现），与骨架无关 → 任何输出为 (B,2,65,65) 的模型都能接入现有两阶段管线（这是 exp3xx 的关键前提，已在 `models_alt.py` 验证）。

## 2. 各架构调研细节

### 2.1 U-Net CNN（→ exp301）
- **证据**：EXL-50U（中国球形环）AI 平衡重建基准论文对多种 NN 的对比结论——CNN 在计算成本、精度与泛化（OOD 放电）之间最佳平衡；与 FNO 并列最稳。
- **设计**：depth 4、base_width 24（通道 [24,48,96,192]+bottleneck 192），块 = 2×Conv3×3+GELU，MaxPool 下采样，双线性上采样（显式 `size=`，绝不 scale_factor——65 非 2 的幂），**无归一化**（与 FNO 基线对齐，避免 BN 在 batch 16 小样本下的统计问题）。
- **预期优势**：局部卷积对 J（ψ 二阶导）的微结构更友好；训练/推理快。
- **预期风险**：感受野由堆叠深度决定，需要足够的层数覆盖磁面全局耦合。

### 2.2 UFNO 傅里叶 U-Net（→ exp302）
- **证据**：UFNO/F-FNO 系列文献——把 FNO 的谱混合嵌入 U-Net 的多尺度结构，局部细节与全局结构同时建模。
- **设计**：lift 18→64；编码器 4 级 + bottleneck 全用 `SpectralConv2dR`（复用 exp102 的 cfloat 谱权重，65² 非 2 的幂有 min-guard）：65²→32²→16²→8²，宽度/模态数随分辨率收缩 [64/16², 64/16², 32/8², 32/4²]，bottleneck modes 4×4；解码器普通 conv 上采样块；proj 64→2。
- **预期优势**：比 FNO 参数利用率高（2.47M vs 4.21M），多尺度谱核理论上更契合磁面的大尺度结构。
- **预期风险**：解码器普通 conv 可能成为瓶颈（只学局部上采样）。

### 2.3 FNO-KAN 混合（→ exp303）
- **证据**：KANO（FNO 谱瓶颈 + 自适应基函数）在变系数 PDE 上报告显著收益；GS 的 Δ\* 是变系数算子。
- **KAN 轨经验**：点式 B-spline KAN（每像素独立 KANLayer，无卷积混合）在 65² 上失败（20.87%）——问题不在 KAN 本身而在**缺乏空间混合**。exp303 是相反的组合：**保留 FNO 的谱混合骨架，只把块内 1×1 conv 换成 KAN 激活**。
- **设计**：FNO2d2608 骨架（lift 18→64 + 4×FNOBlock 16² 模态 + proj），块 = `GELU(SpectralConv2dR(x) + KANConv1x1(x))`。KANConv1x1 = 每像素 KAN：`φ(x) = wb·silu(x) + ws·Σ_b c_b·B_b(x)`（同 `model_kan.KANLayer`），grid 4/degree 2（6 基函数），融合 matmul 实现（不物化 (N,in,out) 中间张量）。4.33M 参数。
- **实现偏差（README 记录）**：
  1. **tanh 门控**入样条域 [-1,1]（谱后激活无界，样条 knot 固定 [-1,1]；silu 基分支保留无界路径）；
  2. **基函数 stop-grad**：基函数值在 `no_grad` 下计算（对 KAN 参数梯度零影响；仅裁剪 x→样条 的梯度路径；tanh 饱和区该路径本就趋零；使 fwd+bwd 从 55.7→~22 ms/块，800-epoch 训练从 ~4.5h → ~1.5h）；
  3. **coeffs 零初始化**（φ(x) ≈ wb·silu(x) 起步，稳定，同 KANLayer 约定）。
- **性能**：基函数用批量 Cox-de Boor 递归（O(p) 次逐元素运算）替代 `model_kan._bspline_bases` 的逐索引 Python 循环（O(G+p) 次宽张量临时分配，GPU 上 96→39 ms/次，交叉验证 max err 8e-6）。
- **预期风险**：KAN 参数多（+3% vs FNO），小样本 N=500 下过拟合；grid 4 若不稳定回退 grid 2。

### 2.4 PI-DeepONet（→ exp304）
- **证据**：SUNIST-2 课题组用物理约束 DeepONet 做 GS 平衡重构，~100 个放电即可训练；Cai et al.（CMAME 2022）证明 DeepONet 对带噪输入的稳健性（线圈电流实测值天然带噪）。
- **设计**：分支 ×2（16→256×3 层 GELU，输入 = z-score 标量 `x[:,2:].mean((2,3))`——5 参数 + 11 电流，均值广播后每像素相同，取 mean 即原值）；共享主干 MLP（(R,Z)→256×3 层，输入 = 归一化坐标网格）；输出 = 分支·主干 einsum 点积 → (B,2,65,65)；主干末层权重 ×0.1（小初始化保证线性起步）。0.60M 参数。
- **预期优势**：全局标量输入→场输出的结构最贴合本问题输入分解；逐点评估使物理损失天然成立；对线圈噪声稳健。
- **预期风险**：0.60M 容量显著低于其他骨架（1/4~1/7）——若阶段1 卡在 3% 阈值外走 e300 兜底，如实记录；也可能需要更长训练。

### 2.5 WNO（暂缓）
局部化小波核（Wavelet Neural Operator）适合非 2 的幂网格与边界奇异性，但需 pywt 依赖且现有 SpectralConv2dR 已带 min-guard 处理 65²——收益未证实，留档不做。

## 3. 共同基线：两阶段 PINO 方案（exp102 口径）

所有 exp3xx 实验共享 exp102 的两阶段方案，仅 `--model` 骨架不同：
- 阶段1：`MSE(ψ_plasma) + w_j·masked_mse(J_z, core)`（纯监督）；val rel L2 < 3% 切阶段2（e300 兜底）；
- 阶段2：加 `ramp(30) · (w_pde·l_pde + w_ip·l_ip)`（物理权重预热 ramp，防切换爆炸）；GS 残差在物理域反归一化后计算；
- coil 分离：网络只预测 ψ_plasma，ψ_total = ψ_plasma + Σ I_k·G_k（Greens 解析加回）；
- 训练：AdamW 1e-3/wd 1e-4、ReduceLROnPlateau、batch 16、800 epochs、阶段2 早停 patience 75、N=500 seed 1。
