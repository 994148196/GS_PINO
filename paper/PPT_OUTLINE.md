## 〇、开场（P1–P3）

### P1 标题页
- 标题：面向托卡马克平衡的 GS 方程神经求解：从可测量量到物理约束再到架构比较
- 副标题：MAST/MASTU 数据 · 两阶段 PINO · 14 种架构系统对比 · 40+ 实验
- 配图：`exp101_pino_rhs_n500/figures/fig1_best_worst_psi.png`（装置+线圈+磁面，视觉锚点）

### P2 任务与物理背景
- GS 方程 Δ*ψ + μ₀R·Jφ = 0：ψ 决定磁面拓扑（X 点、分离面、Ip）
- 为什么用神经网络：freegs 求解 ~1 s vs GPU 前向 1.6 ms（**665×**），实时控制/优化需要
- 任务形式化：18 通道输入（R,Z + 5 工程参数 + 11 线圈电流）→ ψ_plasma + Jφ 双输出
- coil 分离：网络只学等离子体场，线圈场解析加回（greens 恒等式 6e-8 Wb）
- 配图：`ppt_assets/training_twostage.png`（下半部分含 coil 分离公式）；或 exp101 README 的通道表

### P3 评估指标（本工作特色：物理自洽维度）
- 精度：rel L2（plasma/total）、RMSE(Wb)
- 物理：GS 残差（pred/truth，自洽性）、Ip 相对误差、mask 内 J rel L2
- 几何：X/O 点定位误差（cm）、n_xpt_fail
- 一句话：**不止"像不像"，还要"物理对不对"**

## 一、端到端与数据（P4–P7，exp001–013）

### P4 数据集演进（一页时间线）
- v1 固定几何 → v2 alpha 剖面采样 → v3 几何扩展**失败**（isoflux 约束不可达）
  → v4 可行区采样 + 7 项接受检查（**恢复 9–49×**）→ v5 MAST DN+SN → v6 五配置 129² 真实壁
- 论文复现冻结基线：N=5000 test 0.056%（全档超论文）
- 核心教训：**数据物理合理性 > 输入架构**；超定系统约束残差必须显式检查
- 配图：EXPERIMENTS.md §2 表格精简版（自绘）

### P5 端到端：coil 电流输入（exp001/011）
- X 点坐标 → 线圈电流：只给可测量量直接出 ψ，无需磁面重构中间环节
- 代价 ~1.4×；位形识别成为隐含能力（信息完全由 11 路电流承载）
- 配图：`exp011_model_b18ch_coils_mix/figures_dn/`（fig1）

### P6 位形泛化（exp008/009/010）
- 混合训练：+26~35% 代价换来跨位形泛化；**专职模型外推崩溃**（DN→SN 253%、SN→DN 4.0e8%）
- config 标签冗余：反事实翻转→54×/23× 崩溃；去掉标签→**反而略优**（自推断更稳）
- 配图：exp008/009 figures 对比（一页双图）

### P7 五配置端到端 + 数据清洗（exp012/013）
- snow/limiter 位形 1.3–1.8% 健康（雪点二阶约束位形最优）；DN/SN 偏高（129²+SN 真值形态质量）
- 清洗收益分解：dn/snow_double 是模型真实收益（−10%），**sn 改善主要来自 test 剔除病态**——剔除宜保守，生成侧修复优于事后筛选
- 配图：`exp013_clean_v6/figures`（或 exp012）

## 二、物理约束 PINO（P8–P11，exp101–106、201–203）

### P8 为什么纯监督不够 → 两种做法
- 纯 MSE 给不出：ψ↔J 自洽、Ip 积分约束、PDE 结构先验
- 做法1：RHS 固定 GS 残差（单阶段，J 来自数据）
- 做法2：**两阶段**——阶段1 监督 ψ+J，阶段2 自洽残差 + Ip 约束
- 配图：`ppt_assets/training_twostage.png` ⭐

### P9 两阶段细节与"爆炸"教训
- 切换判据 val rel L2 < 3%（e300 兜底）；早停 patience 75 仅阶段2
- **物理权重必须 warm-up ramp**（0→目标 30 epochs）——首版突加 → 阶段2 首 epoch 爆炸摧毁阶段1
- 结果（exp102）：test 0.80%、Ip 0.21%、J 1.36%、GS 残差 3.8× FD 下限——**纯监督拿不到的自洽性**
- 配图：`ppt_assets/training_twostage.png`（同页展开）；可加 exp306 作权重反例

### P10 推广：混合位形与五配置（exp103–106）
- 混合 DN+SN（exp103/104）：做法1 混合代价**为零**（0.70% vs DN-only 0.72%）——PDE 项吃掉共享容量代价；SN 桶增益最大
- 五配置（exp105/106）：做法1 全面增益 −22%；做法2 自洽未建立（阶段1 严阈值不可达 + 早停掐断）——如实记录
- 配图：exp105/figures_all 的 fig2（六桶误差分布）

### P11 数据源替换（exp201–203）
- gspack2_TRAE vs freegs：**分布等价 ≠ 误差等价**（+0.5pp 超判据；交叉评估证明数据固有下限）
- exp203：生成侧质量门全部生效，但**"更干净"≠"更容易学"**——质量与可学习性正交
- 配图：exp201 README 交叉评估矩阵表

## 三、架构对比（P12–P21，exp301–314，核心章节）

### P12 对比设置（公平性声明）
- 同数据（v5/dn N=500）、同两阶段协议、同超参、同 seed——**唯一变量 `--model`**
- MODEL_REGISTRY 注册表：一个接口 (B,18,65,65)→(B,2,65,65)，全手写 PyTorch
- 13 个架构 × 1 张总表预告（悬念）

### P13 FNO 基线（exp102）
- 配图：`ppt_assets/arch_fno.png` ⭐
- 要点：谱卷积=全局混合（固定模态）；0.80% / 4.21M / ~15 min

### P14 UNet——纯卷积失败（exp301）
- 配图：`ppt_assets/arch_unet.png` ⭐
- 要点：2.202%（2.75×）、X 点 3-4×、GS 残差 4.3×——局部感受野不足承载磁面全局拓扑
- 意义：**全局性假设的诞生**（文献"CNN 最佳"不迁移：该基准无物理约束）

### P15 UFNO——多尺度谱（exp302/305）
- 配图：`ppt_assets/arch_ufno.png` ⭐
- 要点：0.729% 击败 FNO（−9%）、参数 0.59×；高分辨率保细节 + 低分辨率承载全局
- exp305 架构调优 0.7147%（噪声内）；exp306 训练侧调优负收益（权重杠杆已吃满）

### P16 FNO-KAN（exp303）
- 配图：`ppt_assets/arch_fnokan.png` ⭐
- 要点：0.857% 与 FNO 差 ≤0.1pp——KANO"变系数需可学习激活"论点未转化；4× 训练时长
- 与点式 KAN（1.3k 参数 20.87%）合证：**KAN 可工作但不更好**

### P17 PI-DeepONet——容量奇迹（exp304/307）
- 配图：`ppt_assets/arch_deeponet.png` ⭐
- 要点：0.60M（FNO 1/7）追平 FNO；加宽 1.34M → **0.7575% 反超**、Ip −45%
- 分支-主干分解与"标量条件→场"精确同构；J/Ip 短板 = 容量问题，加宽即愈

### P18 TKNO-lite——Transformer 算子（exp311，系列最优）
- 配图：`ppt_assets/arch_tkno.png` ⭐
- 要点：**0.635%**（−11% vs 上一位）、J 0.977%/X 0.42/O 0.18 全最佳、1.21M（FNO 0.29×）
- 结论：**决定变量是混合的全局性，不是傅里叶实现**；代价 80 min（无 flash 注意力）

### P19 POD-DeepONet——低秩封顶（exp312，诚实负面）
- 配图：`ppt_assets/arch_pod_deeponet.png` ⭐
- 要点：SVD 自动判据 p_psi=3（99.92% 能量）→ 封顶 1.508%（exp307 的 2×）
- **能量判据 ≠ 精度判据**：截断的 0.08% 恰是 X 点尺度结构；p_psi=3 = 数据集低秩诊断
- 配图（可选）：exp312/figures/fig1（X 点误差可见）

### P20 POD + 残差——诊断的落地修复（exp313/314）
- 配图：`ppt_assets/arch_pod_residual.png` ⭐
- exp313（FNO 残差）：0.883%（**−41%**）、X 点反超 FNO、870K 参数——修复成立
- exp314（UNet 残差）：1.099%（−27%）——**基外细节"部分需要"全局混合**
  （完整任务 2.75× 差距 → 残差任务 1.25×；谱混合仍值 0.22pp）
- 分阶段冻结协议：e1–60 训 branch → e61 冻结 branch 训残差（消除通道竞争）

### P21 总结果表 + 参数-精度全景
- 配图：ALGORITHMS_GUIDE.md §6.1 全景表（自绘表格页）

## 四、结论与收尾（P22–P26）

### P22 结论链（证据顺序）
1. 纯局部卷积失败（exp301 vs exp102）→ 全局耦合是硬需求
2. 全局混合是决定变量、不是傅里叶（exp302/311 成功 vs exp301 失败）
3. 多尺度谱 > 单尺度谱（exp302 vs exp102）
4. 分支-主干是最经济的局部解（exp304/307）
5. KAN 可工作但不更好（exp303 + 点式 KAN）
6. 低秩先验单独封顶、并联残差可修复（exp312→313/314）；残差任务的全局性需求下降但存在

### P23 三条工程教训（跨越所有实验）
- 数据：物理可行性检查 > 一切（v3→v4 恢复 9–49×）；"更干净"≠"更容易学"（exp203）
- 损失：物理项必须 warm-up ramp（爆炸教训）；自洽 + Ip 是纯监督拿不到的（exp102）
- 架构：先问"全局混合放哪里"，再谈容量与花活（全局性分层：完整任务决定性 → 残差任务边际）

### P24 失败清单（省钱清单）
- 表格：损失权重加大（exp306）、trunk 傅里叶特征（exp308 梯度风暴）、POD 独立低秩（exp312）、点式 KAN（20.87%）、UNet 纯卷积（exp301）

### P25 局限与未来方向
- 单 seed 单数据（v5/dn）；跨位形/跨机器未测架构排序；flash 注意力构建（80→15 min）
- 后续：最优架构（exp311）上五配置/混合数据（129² 注意力需重 patch）、N=2000、3-seed 显著性、POD p 扫描、残差通道换注意力
